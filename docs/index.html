CPU-First Architecture

Runs efficiently on standard desktop/laptop CPUs using OpenCV DNN and ONNX Runtime CPU. Zero VRAM requirement, allowing your GPU to focus 100% on LoRA training.

🎯

Identity & Era Verification

SFace & ArcFace R50 embedding matching filters out secondary people and prevents identity drift across different ages or styling periods.

📐

Smart Krea 2 Bucket Fitting

Calculates optimal safe crop frames matching exact aspect ratios (`512x512`, `512x768`, `768x1024`, etc.). Resizes down cleanly without stretching or upscaling.

Multi-Stage Curation Pipeline

How Lora Face Select Lite transforms raw photos into dataset-ready crops.

1

Raw Input & Video Frame Extraction

Scans dataset folder for images and video clips. Decodes frames sequentially at 0.5 FPS with memory-capped top-K selection.

2

Face Detection & Cosine Similarity Gate

YuNet isolates face bounding boxes. SFace / ArcFace R50 extracts 512-d feature vectors to match against 1–5 reference images.

3

BiSeNet Facial Feature Segmentation

Generates detailed parsing masks for hair, skin, glasses, and headwear to calculate hair density and occlusion margins.

4

MediaPipe Pose & NudeNet Safety Check

Estimates 33 body keypoints. Checks hand/wrist boundaries and runs optional NudeNet ONNX model over the target body region.

5

Bucket Alignment & Interactive HTML Report

Fits crop into nearest Krea bucket (`512, 768, 1024`). Generates `review.html`, `dataset_manifest.csv`, and `contact_sheet.jpg`.

Quick Start Guide

Get up and running in under 2 minutes on Windows or Linux.

Windows PowerShell Installation
# 1. Clone repository & set up environment
PS> cd F:\AI_project\lora_face_select_lite
PS> py -3.12 -m venv .venv-win
PS> .\.venv-win\Scripts\Activate.ps1

# 2. Install dependencies & download pre-verified ONNX models
PS> python -m pip install -e ".[test]"
PS> python -m lora_face_select_lite download-models --profile stable
PS> python -m lora_face_select_lite doctor

# 3. Launch GUI or run CLI select command
PS> python -m lora_face_select_lite.gui # Or double click run_gui.bat

Generated Dataset Artifacts

Full auditability for every crop decision and safety check.

Artifact Path Description & Purpose
prepared/ Ready-to-upload cropped images aligned to exact Krea buckets (`512, 768, 1024`).
selected/ Unmodified original source files corresponding to approved crops.
review.html Interactive visual report with side-by-side comparison of original, crop, face parsing & pose keypoints.
dataset_manifest.csv Complete CSV with similarity score, focus target (`body` vs `identity`), pose confidence, and bounding box coordinates.
crop_skipped/ Files where safe standard Krea crop was impossible, with exact diagnostic reason in `crop_skips.csv`.
contact_sheet.jpg Grid preview of all selected candidates for quick manual review.
